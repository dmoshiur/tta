# Content

The CMS supports `ARTICLE`, `BOOK`, `KNOWLEDGE`, `WORLD`, `HUMANITY`, and `SOCIETY`, with draft/published/scheduled states, sanitized rich HTML, author, category, image URL, sources, dates, excerpt, and SEO JSON. Public APIs return published records only. World-affairs editors should structure work as event, background, causes, actors, perspectives, implications, sources, and explicitly label fact/analysis/opinion.
